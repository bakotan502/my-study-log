# 学習ログ

日々の学習時の調子や学習メモを記録し、あとから見返せるシンプルな学習ログアプリです。

日付、今日の調子、学習メモを入力して保存できる静的サイトで、ブラウザの `localStorage` に記録が残ります。保存後は学習記録の一覧表示、検索、編集、削除、調子での絞り込みや推移の表示まで行えます。

## 主な機能

- 日付入力と自動日付補完
- 5段階の学習時の調子の選択
- 今日の学習メモの保存
- 学習記録の一覧表示と最新記録のプレビュー
- 記録の編集と削除
- メモテキスト検索
- 調子のフィルター
- 最近の調子の変化をSVGで可視化するグラフ

## 技術スタック

- HTML
- CSS
- JavaScript
- localStorage

## 起動方法

ビルドツールや依存パッケージは不要です。

1. このリポジトリをクローンまたはダウンロード
2. `index.html` をブラウザで開く
3. 学習記録を入力して保存する

```bash
python3 -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` を開いて利用できます。

## データ保存

アプリは `tiny-diary.entries.v1` というキーで `localStorage` に記録を保存します。以前の日記アプリで保存した記録もそのまま表示されます。
